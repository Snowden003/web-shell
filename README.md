# 🌌 Red Sky Web Shell

**Red Sky** is a lightweight and simple web shell that allows you to manage files and execute system commands on a server directly through your browser.

> ⚠️ Warning: Using this tool on servers you do not own or have permission to access is illegal. Use only on your own server or with explicit authorization.

---

## 🛠️ Features

- File and directory management  
- Upload and download files  
- System command execution  
- Quick file editing  
- Clean and minimal interface  

---

## 🚀 Installation

1. Upload the `red_sky.php` file to your desired directory on the server.  
2. Open your browser and navigate to:  
   `https://example.com/red_sky.php`  
3. The Red Sky web shell interface will load.
